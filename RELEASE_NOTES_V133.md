# ANI Police Academy V133 — Release Candidate

## Release focus
V133 is a release-candidate preparation step. It does not claim that the app has been submitted to Google Play.

## Required before public launch
1. Deploy the backend over HTTPS.
2. Provision production PostgreSQL and run all migrations.
3. Configure production Cashfree credentials and webhook.
4. Complete UPI/card payment tests for all four plans.
5. Run the complete QA checklist.
6. Generate a signed Android App Bundle (`.aab`).
7. Complete Play Console policy declarations and billing compliance.
8. Perform internal/closed testing before production rollout.
